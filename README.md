# JavaScript Homework Ejercicios 1

Proyecto de practica con 9 ejercicios de JavaScript enfocados en manipulacion del DOM, eventos, logica, temporizadores, filtros, generacion de datos y persistencia con localStorage.

## Ejercicios incluidos

1. Cambiador de color de fondo
2. Contador de clicks
3. Lista dinamica
4. Filtro de busqueda en tiempo real
5. Calculadora sencilla
6. Temporizador con inicio, pausa y reinicio
7. Generador de contrasenas aleatorias
8. Contador de palabras y caracteres
9. Lista de tareas con localStorage

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Vite
- localStorage

## Funcionalidades destacadas

- Manipulacion del DOM con JavaScript.
- Manejo de eventos como click, input, keydown y change.
- Persistencia de datos con localStorage.
- Renderizado dinamico de listas y resultados.
- Validaciones basicas de formularios.
- Busqueda filtrada por nombre, apellido, posicion o todos los campos.
- Publicacion del proyecto con GitHub Pages.

## Despliegue

El proyecto esta preparado para publicarse en GitHub Pages usando GitHub Actions.
